# Expense Tracker

A responsive web app to track income and expenses, built as part of my **Frontend Development Internship at CodSoft**.


## Features
- Add income and expense transactions with description, amount, category and date
- Form validation for empty or invalid values
- Transaction history showing date and category
- Total income, total expenses and current balance, calculated automatically
- Edit and delete transactions
- Filter transactions by category
- Summary cards for a quick financial overview
- Data saved in Local Storage, so it stays after refreshing the page
- Responsive layout for desktop and mobile

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (DOM manipulation, Local Storage)

## How to Run
1. Download or clone this repository.
2. Open the `ExpenseTracker` folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**
   (or simply open `index.html` in your browser).

## How to Use
1. Choose the type (Expense or Income).
2. Enter a description, amount, category and date.
3. Click **Add transaction**.
4. Use **Edit** or **Delete** on any item in the history.
5. Use the **Show** dropdown to filter by category.
